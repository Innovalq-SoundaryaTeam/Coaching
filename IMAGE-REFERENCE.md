# Image Reference — LS Academy Template

Every image in this template is a **real local file** sitting in
`assets/images/` — there are no remote URLs to hunt down. Each
placeholder photo is a labeled color-block JPG whose filename tells you
exactly what it is and which page(s) it appears on. To replace one:

1. Find the **filename** for the image you want to change in the list
   below (e.g. `coaching-hero-classroom.jpg`).
2. Open the `assets/images/` folder and locate that file.
3. Save your own photo **over it, using the exact same filename**
   (same name, same `.jpg` extension) — for best results, crop it to a
   similar aspect ratio to the placeholder first.
4. That's it — every page that uses that filename updates automatically,
   since they all point at the same file. No HTML editing required.

If you'd rather use a different filename or format (`.png`, `.webp`),
add the new file to `assets/images/` and then update the `src="..."`
attribute in the relevant `.html` file(s) to point at it instead —
the page list below tells you exactly which files to edit and how many
other pages share that same image.

**Repeated images** — the same photo reused across several pages (e.g.
every faculty member's headshot appears on both `faculty.html` and
`about.html`, and the logged-in student's avatar repeats across all 7
student dashboard pages) — only need to be replaced **once** in
`assets/images/`, since every page loads the same file.
